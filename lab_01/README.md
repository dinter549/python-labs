# Лабораторная работа № 1

## Описание

Консольная программа toolkit включает калькулятор арифметических
выражений и конвертер единиц измерения.

Для вычисления выражений не используются
eval, exec, ast.literal_eval и сторонние библиотеки разбора выражений.

## Возможности калькулятора

- Целые и дробные числа с десятичной точкой.
- Сложение, вычитание, умножение и деление.
- Приоритет умножения и деления перед сложением и вычитанием.
- Унарные знаки плюс и минус.
- Пробелы между числами и операторами.

Поддерживаются выражения вида `2*-3`, `2--3` и `1+-2`.
Перед числом допускается один унарный знак.
Выражения `--3` и `2*--3` считаются ошибочными.

Скобки, степень, целочисленное деление и остаток от деления
не поддерживаются.

## Возможности конвертера

| Величина | Единицы |
| --- | --- |
| Длина | mm, cm, m, km |
| Масса | g, kg |
| Температура | c, f, k |

Регистр обозначений не имеет значения: `CM` и `cm` равнозначны.

Преобразования между разными группами единиц запрещены.
Температура не может быть ниже абсолютного нуля.

## Требования

Python 3.12 или новее.

Все команды ниже выполняются из папки `lab_01`.

## Установка

Создать и активировать виртуальное окружение.

На macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

На Windows в командной строке cmd:

```bat
py -m venv .venv
.venv\Scripts\activate.bat
```

Установить зависимости и проект:

```bash
python -m pip install -r requirements.txt
python -m pip install -e .
```

## Запуск

Показать справку:

```bash
python -m toolkit --help
```

Вычислить выражение:

```bash
python -m toolkit calc "2+3*4"
```

Результат: `14.0`.

Использовать унарный минус:

```bash
python -m toolkit calc "2*-3"
```

Результат: `-6.0`.

Если выражение начинается с минуса, перед ним нужно поставить `--`:

```bash
python -m toolkit calc -- "-2+3"
```

Результат: `1.0`.

Преобразовать единицы длины:

```bash
python -m toolkit convert 150 --from cm --to m
```

Результат: `1.5`.

Преобразовать температуру:

```bash
python -m toolkit convert 0 --from c --to f
```

Результат: `32.0`.

Также доступен запуск через файл main.py:

```bash
python src/main.py calc "2+3"
```

## Обработка ошибок

Программа обрабатывает:

- пустое выражение;
- недопустимые символы;
- неправильную последовательность чисел и операторов;
- отсутствие операнда;
- деление на ноль;
- неизвестные или несовместимые единицы;
- некорректное числовое значение;
- значения NaN и бесконечности в конвертере;
- температуру ниже абсолютного нуля.

При успешном выполнении результат выводится в stdout,
а код завершения равен 0.

При ошибке ввода сообщение выводится в stderr,
а код завершения равен 2.

## Структура исходного кода

| Файл или папка | Назначение |
| --- | --- |
| src/main.py | Дополнительная точка входа |
| `src/toolkit/__init__.py` | Обозначение пакета toolkit |
| `src/toolkit/__main__.py` | Разбор аргументов и консольный интерфейс |
| src/toolkit/calculator.py | Разбиение выражения на токены, проверка и вычисление |
| src/toolkit/converter.py | Преобразование единиц измерения |
| src/toolkit/constants.py | Константы и таблицы единиц |
| src/toolkit/errors.py | Классы исключений |
| tests/test_calculator.py | Тесты калькулятора |
| tests/test_converter.py | Тесты конвертера |
| tests/test_cli.py | Тесты консольного интерфейса |
| pyproject.toml | Метаданные проекта и настройки инструментов |
| requirements.txt | Зафиксированные версии зависимостей |

Вычисления отделены от консольного интерфейса.
Модули calculator.py и converter.py не используют print и input.

## Проверки

Запустить тесты:

```bash
python -m pytest
```

При запуске тестов автоматически измеряется покрытие пакета toolkit.
Минимально допустимое покрытие настроено на 81%, что соответствует
требованию: больше 80%.

Проверить код с помощью Ruff:

```bash
ruff check .
```

Проверить аннотации типов:

```bash
python -m mypy src tests
```

Тесты вычислительных функций вызывают их напрямую.
Тесты консольного интерфейса запускают программу отдельным процессом
и проверяют вывод и код завершения.
